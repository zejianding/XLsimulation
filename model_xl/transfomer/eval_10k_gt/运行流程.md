# eval_10k_gt/ · 运行流程（逐物种：预测谱 vs 原谱 余弦）

对每个物种，用它的**全部唯一 (肽,电荷)**（来自该物种 MGF 的 `SEQ=/CHARGE=`）各预测一张谱（V20 或 Prosit），
与该肽在**该物种内**的**全部**实测谱算余弦（PiPrime 嵌入空间），逐肽取**平均**。
全程**流式、内存有界**；所有结果 **CSV**（无 JSON）；**物种之间不合并**。

## 口径（已锁定，两侧对齐）
- **预测侧不做强度过滤（rel=0）**：预测谱原样导出参与嵌入，V20 与 Prosit **同一规则**（都是"不过滤"）；
- **实验侧**统一交给 PiPrime 编码器自身预处理（两侧一致）；
- 因此对比的是"各自导出管线的端到端谱相似度"（V20=模型+**聚类后处理 v20_pp4**；Prosit=Koina+reanchor 官方 b/y）。
  仍存在的固有差异（峰构成 isotope/loss、强度标定）**按要求不做额外对齐**，仅在报告中注明。
- **V20 导出两种模式**：`POSTPROC=cluster`（默认，v20_pp4 聚类后处理）或 `POSTPROC=none`（裸网格→峰，仅 m/z 合并，
  无聚类/扩展/重排/表达校准；`RAW_MIN_INTENSITY` 控制下限，默认 0.01）。
- **对齐 FDR 侧的处理（raw 口径）**：`MERGE_TOL=0.05`（= ds step4 的 `--mz-merge-tol`）、
  `RAW_MIN_INTENSITY=0.01`（= ds `--spec-min-intensity`）、`MIN_MZ=100`（= ds `DEFAULT_MIN_MZ`）；
  强度过滤按 **rel 0/0.05/0.10/0.20** 在变体步骤施加（等价于 ds 打分时按 `rel×pmax` 过滤预测峰，下限 0.01），
  实验谱统一 `sqrt_clip`（= ds/fdr 默认 `--exp-transform`），Prosit 侧另加 `sqrt` 预测强度对齐。
- **Prosit 导出口径（与 FDR/no-FDR 同源）**：调 Koina（按无修饰骨架）→ 只保留 b/y（按 annotation）→
  **把每条 b/y 的强度放回"该肽修饰校正后的理论 m/z"（reanchor）**，值同 `ds/step4_prosit_score.py` 的约定；
  可选开关：`P4_BYONLY=1`（停在 b/y 过滤，用 API 原始 m/z，不 reanchor/不合并）、`P4_RAW=1`（API 全量行原样，含非 b/y）。
- `run_cosine_by_rel.sh` / `filter_group_predictions.py` 只作**可选敏感性分析**（rel 档对 V20 实测无影响、对 Prosit 有影响），**不进入主结果**。

## 步骤（与 transfomer/run_v20_eval.sh 顺序一致）

| # | 脚本 | 输入 | 关键参数 | 输出 |
|---|---|---|---|---|
| 0 | make_peptide_npz.py | 9物种 MGF（SEQ=/CHARGE=） | `--per-species 1111 --max-len 30` | `data/v20_10k_9species.npz`（inputs 网格/masks/charges/pepmasses/seqs） |
| 1 | predict_npz_to_mgf.py（V20） | 输入 NPZ + CKPT | `--device cuda:N --postprocess_mode cluster --cluster_scene v20_pp4` | `predicted.mgf`、`predicted_summary.txt` |
| 1'| prosit_predict_mgf.py（Prosit） | 同一 NPZ | `--batch-size 1500 [--cache …]` | `predicted.mgf`（Koina 预测，reanchor 放修饰位） |
| 2 | collect_original_with_prediction.py | `predicted.mgf` + ROOT_DIR | — | `Grouped_MGFs/<seq>_charge<z>_<hash>.mgf`（该肽全部原谱 + 1 预测谱）、`group_map.csv` |
| 3 | piprime_embedding/mgf_to_embedding_batch.py | `Grouped_MGFs` + PiPrime ckpt | — | `Embeddings/<stem>.npz`（逐组编码，需 GPU/cupy） |
| 4 | batch_cosine_summary.py | MGF + Embeddings | — | `cosine_summary.csv` |
| 5 | cosine_detail_csv.py | MGF + Embeddings | `--limit N`（可选调试） | **`cosine_summary.csv`（逐肽）+ `cosine_detail.csv`（逐谱）** |

## 结果矩阵（全口径一次产出，最后统一汇总）

对每次 run（`Grouped_MGFs` 已就绪）批量生成多口径结果，**全部保留**：

```bash
# V20（pp / raw 两种导出各跑一次矩阵；Prosit 用 PRED=sqrt）
RUN_DIR=$(ls -dt output/v20pp_mouse_*  | head -1) PROJ=raw,grid RELS=0,0.05,0.10,0.20 EXP=sqrt_clip PRED=none ADD_EXPNONE=1 bash run_matrix.sh
RUN_DIR=$(ls -dt output/v20raw_mouse_* | head -1) PROJ=raw,grid RELS=0,0.05,0.10,0.20 EXP=sqrt_clip PRED=none ADD_EXPNONE=1 bash run_matrix.sh
RUN_DIR=$(ls -dt output/prosit_mouse_* | head -1) PROJ=raw,grid RELS=0,0.05,0.10,0.20 EXP=sqrt_clip PRED=sqrt ADD_EXPNONE=1 bash run_matrix.sh
# 汇总（生成的每个 cosine_summary.csv 都会进同一张表）
python collect_results.py --root output --out 汇总矩阵.csv     # + 汇总矩阵_pivot.csv
```
轴与命名：`variants/<投影raw|grid>_rel<lvl>_exp<exp>_pred<pred>/Grouped_MGFs_rel<lvl>/`；
`grid` = 先把原谱投影到 V20 网格再编码（对应 `run_v20_eval.sh` 的 PROJECT_REAL_TO_GRID=1 口径）。
成本：每个变体一次 PiPrime 编码（每组 5–9k，GPU 分钟级）→ 每物种 ~10 个变体 ≈ 20–30 分钟；九物种 ~3–5 h。

## 一键（**逐物种独立**，推荐）

物种之间**不合并**：每个物种用**自己的肽表**、**自己的原谱目录**，产出各自 `output/<pred>_<sp>_<stamp>/`。


产物：`output/<name>_<时间戳>/`（见 `列说明.md`）。

## 内存安全（为什么不爆）
- 步骤 2 单遍扫全部原谱，**命中即 append 写盘**，不缓存原谱；内存仅目标肽集合与计数。
- 步骤 3/5 **逐组**处理（每组=1 肽），算完即写 CSV 行并释放。
- Prosit 先**去重批量预测**（缓存落少量分片），再逐肽写 MGF。

## 各脚本作用
- **依赖（已补进 `../`，与 0701 同布局）**：`predict_npz_to_mgf.py`、`cluster_postprocess.py`、`collect_original_with_prediction.py`、`batch_cosine_summary.py`（0821 清洁版原本没有，已从 0701 拷入并 LF 化）；`predict_mgf.py`、`spectrum_transformer/` 0821 自带。
- **make_peptide_npz.py**：从 GT MGF 抽 `SEQ=/CHARGE=` 去重取 9999 肽，构建 V20 输入网格（39,44,6）+ 位置/通道掩码 → NPZ（严格匹配 predict_npz_to_mgf 的键）。
- **predict_npz_to_mgf.py**（仓库自带）：V20 逐肽预测 → 后处理聚类 → MGF；`--device cpu` 可本地小样。
- **prosit_predict_mgf.py**：同一肽表 → Koina `Prosit_2025_intensity_MultiFrag`；修饰肽按 backbone 预测后把 b/y 放回**修饰校正理论 m/z**（reanchor）；输出与 V20 同格式 MGF。
- **collect_original_with_prediction.py**（仓库自带）：按 (肽,电荷) 从原谱目录收集**所有**命中谱，写成每组 MGF（`SOURCE=ORIGINAL` / `MODEL_PREDICTION`，`COMMENT=species:<sp>`，附 `group_map.csv`）。
- **mgf_to_embedding_batch.py**（piprime_embedding）：PiPrime 编码器逐组生成嵌入（本工作里的"cosine"即在该嵌入空间计算）。
- **batch_cosine_summary.py**（仓库自带）/ **cosine_detail_csv.py**（新增）：逐肽汇总 / 逐谱细节，二者均输出 CSV；新增脚本保证**不一次读入全部嵌入**。
- **run_10k_gt.sh**：统一入口（`PREDICTOR=v20|prosit`），串起上述步骤。
