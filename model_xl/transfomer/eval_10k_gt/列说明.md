# eval_10k_gt/ 输出列说明（全 CSV）

运行目录：`output/<name>_<时间戳>/`。

## `cosine_detail.csv`（逐张原谱一行；细节保留）
| 列 | 含义 |
|---|---|
| `group_file` | 所属组文件（即该肽的分组 MGF，`<seq>_charge<z>_<hash>.mgf`） |
| `sequence` | 肽段（含修饰注释，如 `C+57.021…`） |
| `charge` | 电荷 |
| `idx_in_group` | 该谱在组 MGF 中的序号（0 起） |
| `source_tag` | `ORIGINAL`（原谱）/ `MODEL_PREDICTION`（预测谱，1 条/组） |
| `species` | 物种（来自 `COMMENT=species:<sp>`） |
| `spectrum_id` | 原谱 SCANS 标识 |
| `cosine_to_prediction` | **该原谱与预测谱的余弦（PiPrime 嵌入空间）** |

## `cosine_summary.csv`（逐肽一行；= 该肽所有原谱的平均相似度）
| 列 | 含义 |
|---|---|
| `group_file / sequence / charge` | 肽标识 |
| `num_original` | 该肽匹配到的**原谱条数**（>1 时取平均） |
| `num_prediction` | 预测谱条数（=1） |
| `pred_vs_orig_mean` | **预测谱 × 各原谱余弦的平均（主指标）** |
| `pred_vs_orig_std / _min / _max` | 上述余弦的离散度与实际范围 |
| `orig_orig_mean` | 原谱之间两两余弦的均值（该肽原谱自身一致性，参考） |

## 其它产物
| 文件 | 说明 |
|---|---|
| `predicted.mgf` | 预测谱（V20 或 Prosit），`SEQ=`/`CHARGE=` 与输入肽一致 |
| `Grouped_MGFs/<seq>_charge<z>_<hash>.mgf` | 该肽全部原谱 + 1 条预测谱（供逐组核对） |
| `Grouped_MGFs/group_map.csv` | `filename, sequence, charge, original_count, predicted_peak_count, species_counts, output_path` |
| `Grouped_MGFs/missing_original_matches.txt` | 未匹配到任何原谱的预测肽清单 |
| `Embeddings/<stem>.npz` | PiPrime 嵌入（与组 MGF 谱序一致） |
| `predicted_summary.txt` | V20 侧预测过程摘要（Prosit 侧无） |

**对齐 V20 与 Prosit**：按 `sequence`（+`charge`）连接两份 `cosine_summary.csv`；
逐谱层面对比用 `cosine_detail.csv`（同 `group_file` 下 `source_tag=ORIGINAL` 的行一一对应）。
