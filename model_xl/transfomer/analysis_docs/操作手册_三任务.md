# 任务二 · 全量无 FDR（候选池内排名，≤30 对齐 Prosit）

> 目录：`~/seq2mass/v20_0821/transfomer/ds`
> 目标：每张谱在自己的候选池（±10ppm）里取 top1，和真值比 → search accuracy。
> 顺序：建候选池（step1–3）→ V20 打分 → Prosit 打分 → ≤30 过滤汇总。

```bash
cd ~/seq2mass/v20_0821/transfomer/ds

# ① 扫 MGF 里实际出现的修饰 → 生成 configs/mods_config.json（C+57 / M+15.995）
python step1_scan_mgf_mods.py --species mouse --root "$ROOT" \
  --out-dir output/mouse --config-dir configs

# ② 按修饰枚举变体 → data/<sp>/variants_<sp>.fasta（候选库）
python step2_build_candidate_fasta.py --species mouse --root "$ROOT" \
  --mods-config configs/mods_config.json \
  --out-fasta data/mouse/variants_mouse.fasta --out-dir output/mouse

# ③ 每谱 ±10ppm 匹配候选 → data/<sp>/candidates_<sp>_scans.tsv.gz（每谱一个候选池）
python step3_match_by_mass.py --species mouse --root "$ROOT" \
  --fasta data/mouse/variants_mouse.fasta \
  --out-candidates data/mouse/candidates_mouse_scans.tsv.gz --out-dir output/mouse

# ④（V20）对每候选预测谱并打分 → results_step4_<sp>.csv
#    --minimal=精简分支集(d/f/m_by+hsdf/hsdf_mby+dfexp/dfexp_mby)；
#    --rel-intensities 三档过滤；--exp-transform sqrt_clip=V20 训练域
python step4_predict_score.py --species mouse --candidates data/mouse/candidates_mouse_scans.tsv.gz \
  --out-dir output/mouse --minimal \
  --rel-intensities "0.05,0.10,0.20" --exp-transform sqrt_clip

# ⑤（Prosit）对每候选调 Koina 预测并打分（走监督脚本，卡住自动重启、缓存续传）
#    rel 默认含 0（不过滤强度）与 dfexp/dfexp_mby（raw 融合）；GT≤30 天然
SPECIES=mouse BATCH=1500 bash run_prosit_supervised.sh

# ⑥ ≤30 对齐：把上面的结果按"GT≤30 且在候选池"过滤重算 top1/3/10
python results_len30_accuracy.py --csv output/mouse/results_step4_mouse.csv \
  --out output/mouse/len30_accuracy_mouse.json
python results_len30_accuracy.py --csv output/prosit/mouse/results_prosit_mouse.csv \
  --out output/prosit/mouse/len30_accuracy_prosit_mouse.json
```

**产物**：`output/<sp>/results_step4_<sp>.csv`（V20）、`output/prosit/<sp>/results_prosit_<sp>.csv`（Prosit）、
各自的 `len30_accuracy_*.json`（≤30 主表数字）。

# 任务三 · 1% FDR（target-decoy，(D+1)/T）

> 目录：V20 → `~/seq2mass/v20_0821/transfomer/fdr`；引擎 → `fdr_full`。
> 目标：给候选池加"反转 decoy"竞争，按 `(decoy+1)/target ≤ 1%` 划线，数线内 target 数。

### 3a. V20（多 rel 三档；分支 df/dfmby）

```bash
cd ~/seq2mass/v20_0821/transfomer/fdr

# ① 从 in-scope 变体建 target+反转 decoy 库 → data/<sp>/<sp>_td.fasta（回文/相撞剔除）
python step1_build_td_fasta.py --species mouse --root "$ROOT" \
  --out-fasta data/mouse/mouse_td.fasta --out-dir output/mouse

# ② 每谱 ±10ppm 匹配 T/D 候选 → data/<sp>/candidates_<sp>_td.tsv.gz
python step2_match_td.py --species mouse --root "$ROOT" \
  --fasta data/mouse/mouse_td.fasta \
  --out-candidates data/mouse/candidates_mouse_td.tsv.gz --out-dir output/mouse

# ③ V20 预测 + 打分（一次预测遍扫 rel 0.05/0.10/0.20；--save-full 落每候选明细供事后重算）
python step3_score_fdr.py --species mouse --root "$ROOT" \
  --candidates data/mouse/candidates_mouse_td.tsv.gz --checkpoint "$CKPT" \
  --out-dir output/mouse --rel 0.05,0.10,0.20 \
  --branches "d,f_exp;d,f_exp,mby" --exp-transform sqrt_clip --save-full

# ④ 逐分支走 (D+1)/T 曲线 → summary_fdr_<sp>.json（1%/5%/10% 的 n_target、n_decoy）
python step4_fdr_curve.py --species mouse --out-dir output/mouse --fdr-targets 0.01,0.05,0.10

# ⑤（可选）一键九物种替代 ①-④
# SPECIES=all BRANCHES='d,f_exp;d,f_exp,mby' EXP_TRANSFORM=sqrt_clip bash run_fdr.sh

# ⑥ ≤30 版 FDR 重算（按候选骨架≤30 过滤后重走计数；用 --full 明细，无需 GPU）
python step4_fdr_curve.py --species mouse --out-dir output/mouse/le30 \
  --full output/mouse/full_d_f_exp_rel020_mouse.csv.gz \
  --branches "d,f_exp;d,f_exp,mby" --max-len 30 --fdr-targets 0.01
```

# 任务一 · GT 子集全库盲搜（无前体过滤、最严对照）

> 目录：`~/seq2mass/v20_0821/transfomer/fullsearch`
> 目标：库 = 该批谱自己的真肽（+修饰变体+反转 decoy），**不做前体过滤**，
> 每谱与同电荷全库逐条比对取 top1 → 测"光凭碎片谱能否认出自己"。

```bash
cd ~/seq2mass/v20_0821/transfomer/fullsearch

# ① 从 MGF 收真值肽段 → data/<sp>/base_plain.fasta（去重骨架）
python step1_gt_library.py --species mouse --root "$ROOT" --work .

# ② 建库：GT + 修饰变体(target) + 反转 decoy → data/<sp>/library_annotated.tsv.gz
python step2_build_library.py --species mouse --work .

# ③（V20）对整库每条预测谱一次（GPU，~分钟/物种）→ lib_v20_c*.npz
python step3_predict_v20.py --species mouse --work . --gpu 0

# ④（V20）盲搜打分：每谱对全库、取 argmax 与 GT 比
#    --max-gt-len 30 分母限 GT≤30；--max-lib-len 30 库条目限 ≤30（与 Prosit 对齐）
python step4_blind_score.py --species mouse --work . --root "$ROOT" \
  --predictor v20 --max-gt-len 30 --max-lib-len 30 \
  --rels 0,0.05,0.10,0.20

# ⑤（Prosit）调 Koina 预测整库 → lib_prosit_c*.npz（PROSIT_MAX_LEN=30，天然 ≤30）
python step3_predict_prosit.py --species mouse --work .
# ⑥（Prosit）盲搜打分（GT≤30、库天然 ≤30）
python step4_blind_score.py --species mouse --work . --root "$ROOT" \
  --predictor prosit --max-gt-len 30 --rels 0,0.05,0.10,0.20

# ⑦（MS-GF+，本地）小库搜索（GT plain 库+decoy）→ 每谱 top1 vs GT
bash run_msgfplus_local.sh mouse
python step5_msgfplus_acc.py --species mouse --work . --root "$ROOT" \
  --tsv output_msgfplus/mouse/mouse.tsv --scan-offset 0
```

**一键替代**：V20+Prosit → `SPECIES=all PREDICTORS=v20,prosit nohup bash run_fullsearch.sh`；
Prosit 单独 → `nohup bash run_prosit_gt_all.sh`。
**产物**：`output/<sp>/summary_blind_{v20,prosit}_<sp>.json`（各分支 top1_acc / decoy_win）、
`results_blind_<pred>_<sp>.csv`。

## 附：口径要点（三条任务共同的坑）

- **≤30 对齐**：Prosit 只收 ≤30aa；V20/引擎的 ≤30 结果是对全量按"候选/条目 ≤30 + GT 骨架 ≤30"过滤得来（无需重跑，任务二用 `results_len30_accuracy.py`，任务三用 `--max-len 30`）。
- **强度域**：实验谱统一 `sqrt_clip`；Prosit 预测强度另做 sqrt 对齐（否则其强度加权分支失真）。
- **FDR 公式**：统一 `(decoy+1)/target`，与引擎一致。
- **缓存放哪**：Prosit 预测缓存分片存 `predictions/prosit_cache.tsv.gz.seg_*`；FDR 的 decoy 预测单独一份（`--decoy-cache`），互不污染。
- **别混数据源**：≤30 分析统一用 canonical 引擎结果（`Orig-result-tsv`），不要用 fdr_full 的 mzML 版 tsv。
