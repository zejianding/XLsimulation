# FDR 分析流程说明

这篇文档用自然语言讲清楚"v20 谱打分重排的 1% FDR 分析"到底在做什么、每一步为什么这么做。

## 我们想回答的问题

在质谱鉴定里，我们说"这条谱图匹配上了某个肽段"时，必须回答一个问题：这个结论有多可信？如果只管报结果、不管可信度，那随便一个工具都能"鉴定"出很多肽——因为低质量谱图几乎总能硬凑出一个像样的匹配。学术界解决这个问题的方法叫 **target-decoy 竞争（TDC）**：在数据库里掺入一批"肯定不存在"的诱饵序列（decoy），然后要求打分器把真实的 target 和这些诱饵区分开。诱饵和真序列混在一起，打分器把它们分得越开，说明它越可信。

于是我们的实验设计就变成了：给每条真实谱图一个候选池（里面一半是真肽段 target、一半是反转的诱饵 decoy），用 V20 模型给每个候选打一个"和真实谱有多像"的分，取池子里分数最高的那个作为这条谱的鉴定结果。如果打分器真的懂谱，那么分数高的结果应该大多数落在 target 上，落在 decoy 上的就很少。最后按分数从高到低切一条线，保证线上的结果里 decoy 的比例不超过 1%——这条线就是 **1% FDR 线**，线上的 target 个数就是我们的鉴定数。同样一条 1% 的线，我们能鉴定出 3000 个、别人只有 2000 个，那说明我们的打分器在同样的可信度标准下找回了更多真结果——这就是"3000 vs 2000"这个故事。

## 第一步：把 FASTA 变成"target + decoy"两份

我们要从零搭一个诱饵数据库。取物种的 FASTA（小鼠大约 225 万条肽段），每条肽段作为一条 **target**，处理时把每个半胱氨酸 C 加上 +57.021（碘乙酰胺固定修饰，这是质谱前处理的标准修饰，也是这些数据里唯一固定出现的修饰）。然后把这 225 万条肽段**逐条反转**，得到 225 万条 **decoy**。

反转有一个非常关键的性质：**反转不改变肽段的总质量**（氨基酸组成没变，只是顺序反了），所以一条 decoy 和它的 target 有着完全相同的中性质量。这意味着后面按前体质量检索时，只要窗口里捞到了某条 target，就必然能在同样质量的位置捞到它的反转 decoy——target 和 decoy 天然地在每个谱图里五五开，不会出现"诱饵太多把比例带偏"的情况。反转后的序列在真实蛋白质里几乎不可能存在，所以任何一条 decoy 被打成 top1 都必然是错的——这是 FDR 分母的"可靠假阳性"来源。

构建时还有一个细节：如果某条 decoy 反转后恰好等于数据库里某条 target（比如回文序列，或者数据库里同时存在某序列和它的反转），这条 decoy 就必须丢掉，否则一个"诱饵"会真的对应一个"真实序列"，污染整个统计。最后把所有 target 和 decoy 写进同一个 FASTA，每条记录的头部标注它是 T 还是 D、以及它的精确中性质量。

## 第二步：按前体质量把谱图和候选配对

每条 MGF 谱图都带有前体质荷比（PEPMASS）和电荷（CHARGE），两者换算成中性质量后，在第一部建好的 FASTA 里做 ±10 ppm 的质量检索，把质量吻合的所有序列捞出来作为这条谱的候选池。因为 decoy 和 target 质量分布完全一致，所以每条谱的候选池天然就是"一半 T、一半 D"（实测均值 10.4 条 target、10.4 条 decoy），而且几乎所有谱图都有候选。这一步产出的就是一个带标签的候选表：每条谱对应若干序列，每序列标注 T 或 D。

## 第三步：让 V20 给每个候选和真实谱打分

现在关键环节来了——怎么判断一个候选是不是真的"解释"了这条真实谱。我们把每个候选序列喂给训练好的 V20 模型，让它预测这条肽段的碎片谱（一个 39×46×6 的强度网格，覆盖不同断裂位点、不同离子类型、不同电荷态），然后把这个"预测谱"和"真实实验谱"做相似度比较，一共算三个分量：

- **gc（网格余弦）**：把真实谱的实验峰投到模型的 39×46×6 网格上，再和模型预测的网格做余弦相似度。这是 V20 自带的整体对齐方式，衡量"整张谱形状像不像"。
- **d（真实谱投影到预测峰）**：把真实谱的强度取到每个预测峰的位置上，再和预测峰强度算余弦。它惩罚的是"模型预测了很强的峰、但真实谱里根本没有"——即惩罚过度预测。
- **f_bidir（预测峰投影到真实峰）**：反过来，把预测峰的强度取到每个真实实验峰的位置上，再和真实峰强度算余弦。它惩罚的是"真实谱里有很明显的峰、但模型根本没预测到"——即惩罚漏预测。

三个分量都是 0 到 1 之间的余弦/占比值，量纲一致，所以我们把它们**等权取平均**，得到每个候选一个"融合分"。这个融合分是"原始"的、没在谱内做归一化的，因此**可以在不同谱图之间直接比较**——这是后面 FDR 排序的关键前提（一旦在单条谱内做 minmax 归一化，分数就会失去跨谱可比性，无法用来排 FDR 线）。每条谱取融合分最高的候选作为它的 top1，记下它的 T/D 标签和分数。这一步是整条流水线里最重的一步：全量一万条谱、每条约 225 个候选，加起来两百多万次模型前向，GPU 上大约几十分钟。

## 第四步：画 FDR 曲线，切 1% 线

拿到每条谱的 top1（标签 + 分数）之后，把所有谱按 top1 分数从高到低排序，然后从上往下累计：数一数到目前为止遇到了多少条 decoy、多少条 target。**FDR 的定义（Elias–Gygi 惯例）就是累计 decoy 数除以累计 target 数**——比如走到某一刀，已经放了 100 条 target 和 1 条 decoy，那这一刀以上的结果 FDR 就是 1%。因为 FDR 在往下走的过程中不是严格单调的（可能这条线刀下去遇到 decoy、再往下又遇到一串 target），我们给每条谱算一个 **q 值**：它在当前分数以下能实现的最低 FDR。最后 **1% FDR 线**就是"q 值 ≤ 0.01"的最大高分段，也就是能保证假阳性率不超 1% 的最大鉴定集。

这条线上我们报告三个数：**n_target**（线的 target 鉴定数，也就是"3000 vs 2000"的主角）、**n_decoy**（线内混入的诱饵数，应该约等于 n_target 的 1%，作为统计自检）、**n_target_gt_match**（其中真正质量匹配上了 MGF 里真值序列 SEQ= 的条数——如果连真值都对上了，说明这些鉴定不光是"标签对"，还是真的找对了肽段）。

## 怎么读结果、怎么对比

`summary_fdr_mouse.json` 里 `fdr_lines."0.01".n_target` 就是核心数字。两个打分方案（比如我们的 V20 融合 vs 别人家的重排）在**同一套 FASTA、同一份 MGF、同一个 decoy 集、同一个 FDR 公式**下各跑一遍，谁在 1% 线上拿到更多 target 鉴定，谁就更强。因为对比双方用的是完全相同的统计口径，这个"多出来的 3000 个"不是靠放宽标准堆出来的，而是打分器真的把 target 和 decoy 分得更开的结果。
